# 오픈클로(OpenClaw) 설치와 연결 — 한라초 홍보 도우미용

오픈클로는 내 컴퓨터에 설치해 두는 오픈소스 AI 비서입니다. 이 문서는 **홍보 도우미(hongbo)** 를 오픈클로에 붙여
아침 훑기 예약, 텔레그램으로 초안 확인·승인, 로그인해 둔 크롬에서 게시까지 하도록 연결하는 순서입니다.
공식 문서(https://docs.openclaw.ai)의 내용을 2026년 9월 기준으로 옮겼습니다. 화면이 다르면 공식 문서를 우선하세요.

## 0. 준비물
- 늘 켜 두는 Windows PC 또는 Mac (오픈클로는 컴퓨터가 켜져 있을 때만 일합니다)
- AI API 키 1개 (Claude·ChatGPT·Gemini 중 hallahongbo 앱에서 쓰던 키를 그대로 씁니다. 오픈클로 자체도 모델을 쓰므로 사용량이 조금 늘어납니다)
- 텔레그램 계정 (휴대폰에서 초안을 받고 "승인"이라고 답하는 용도)
- Node.js 24 이상 (https://nodejs.org 에서 LTS 설치)

## 1. 홍보 도우미(hongbo) 설치
```powershell
git clone https://github.com/BAEPPY/hongbo.git
cd hongbo
npm install
npm link            # 어디서든 hongbo 명령을 쓸 수 있게 (관리자 권한이 필요하면 PowerShell 을 관리자로)
hongbo help
```
설정:
```powershell
hongbo config set-key anthropic sk-ant-…          # 또는 openai / gemini
hongbo config set-provider anthropic
hongbo config set-photo-root "C:\Users\<이름>\홍보사진"
hongbo config set school.phone 064-740-9500
hongbo config show
```
사진 폴더 아래에 활동별 폴더를 만듭니다. 폴더 이름은 `2026-09-17 2학년 안전체험관 현장체험학습` 처럼 **날짜 대상 활동명** 순서로 쓰고,
사진과 `메모.txt`(예시: `docs/메모_예시.txt`)를 넣습니다. 메모에는 **내용** 한 줄만 있어도 시작할 수 있습니다.

먼저 오픈클로 없이 한 번 돌려 보세요:
```powershell
hongbo scan                                   # 교육청 학교소식 훑기
hongbo draft "안전체험관"                       # 초안 + 사진 준비 (--rank 를 붙이면 AI 가 사진 적합성 판정)
hongbo review "안전체험관"                      # 브라우저 확인 창에서 고치고 승인
hongbo plan "안전체험관"                        # 게시 계획 (오픈클로가 폼을 채울 때 쓰는 값)
```

## 2. 오픈클로 설치
- **Windows**: 공식 문서는 WSL2 를 가장 안정적인 경로로, PowerShell(네이티브) 설치도 지원한다고 안내합니다.
  - PowerShell 로 설치하면 hongbo·크롬·사진 폴더가 모두 Windows 쪽에 있어 경로 문제가 없습니다. 먼저 이 방법을 권합니다.
  - WSL2 로 설치했다면 hongbo 도 WSL 안에 설치하고 사진 폴더는 `/mnt/c/Users/<이름>/홍보사진` 으로 지정하세요. `hongbo plan` 이 사진 경로를 `C:\…` 로 바꿔서 알려 주므로 크롬 첨부에 그대로 쓸 수 있습니다.
- **Mac**: 터미널에서 공식 설치 명령을 실행합니다.
- 설치 뒤 `openclaw onboard`(초기 설정)에서 모델 API 키를 넣고 게이트웨이를 켭니다. 게이트웨이는 **localhost 에만** 바인딩하고 토큰 인증을 켠 상태로 두세요.

## 3. 텔레그램 연결
1. 텔레그램에서 **@BotFather** 에게 `/newbot` 을 보내 봇을 만들고 토큰을 받습니다.
2. 오픈클로에 토큰을 넣습니다 (`channels.telegram.botToken`, 또는 `tokenFile` 로 파일 경로 지정).
3. 기본 DM 정책은 **pairing(짝짓기)** 입니다. 내 텔레그램에서 봇에게 첫 메시지를 보내고, 오픈클로가 보여 주는 승인 절차를 마칩니다. 다른 사람은 말을 걸 수 없게 `allowFrom` 에 내 사용자만 남겨 두세요.
4. 봇에게 "안녕"이라고 보내 답이 오면 연결된 것입니다.

## 4. 홍보 도우미 스킬 붙이기
스킬은 이 저장소의 `skills/` 폴더에 있습니다(복사하지 않고 그대로 씁니다).
```powershell
openclaw config set skills.load.extraDirs '["C:/Users/<이름>/hongbo/skills"]'     # Mac/WSL: ["~/hongbo/skills"]
openclaw skills list          # hongbo-scan, hongbo-draft, hongbo-post 가 보여야 합니다 (hongbo 명령이 PATH 에 있어야 나타남)
```
ClawHub(커뮤니티) 스킬은 설치하지 마세요. 보안 점검에서 12~20% 가 악성이었다는 보고가 있습니다. 필요한 기능은 이 저장소에 더합니다.

## 5. 크롬 붙이기 (게시할 때만 필요)
게시는 **선생님이 인증서로 로그인해 둔 크롬**에서 합니다. 오픈클로가 그 크롬을 다루려면 크롬 확장(OpenClaw Browser Relay)을 연결합니다.
```powershell
openclaw browser extension install
openclaw config set browser.defaultProfile chrome
```
Windows 에서는 확장 설정 화면에서 수동 짝짓기(pairing)가 필요합니다. 짝짓기 문자열은 비밀번호처럼 다루세요.
확장이 어려우면 `user` 프로필(크롬 DevTools 로 붙는 방식)도 됩니다. 이때는 컴퓨터 앞에서 "붙이기 허용" 창을 눌러야 합니다.

## 6. 아침 훑기 예약
```powershell
openclaw automations create "0 8 * * 1-5" "hongbo-scan 스킬로 교육청 학교소식을 훑고 요약을 보내 줘" --name "학교소식 아침 훑기" --tz "Asia/Seoul" --session isolated --announce --channel telegram --to "<내 텔레그램 채팅 ID>"
openclaw automations list
openclaw automations run <job-id> --wait      # 바로 한 번 실행해 보기
```
채팅 ID 는 봇과 대화할 때 오픈클로 로그에 찍히거나, 텔레그램의 @userinfobot 으로 알 수 있습니다.

## 7. 첫 게시는 함께
1. 크롬에서 교육청 누리집(https://www.jje.go.kr)에 **인증서로 로그인**해 둡니다.
2. 텔레그램에서 "「안전체험관」 초안 만들어 줘" → 초안과 사진이 오면 고칠 곳을 말하거나 "승인".
3. "올려 줘" → 오픈클로가 글쓰기 폼을 채우고 **등록 전에 화면 캡처를 보내 묻습니다.** "등록해" 라고 답해야 올라갑니다.
4. 처음 성공하면 오픈클로가 폼 구조를 `hongbo form-notes` 로 기록해 두어 다음부터 빨라집니다.
5. 목록에서 글이 보이는지 눈으로 확인합니다.

## 문제가 생기면
- `openclaw skills list` 에 스킬이 없다: `hongbo help` 가 되는지 확인(PATH), `extraDirs` 경로 확인.
- 게시 중 "글쓰기 버튼이 없다": 크롬에서 로그인이 풀린 것. 다시 인증서 로그인 뒤 "됐어".
- 사진이 첨부되지 않는다: `hongbo plan` 의 사진 경로가 크롬이 읽을 수 있는 경로(C:\…)인지 확인.
- 비용이 걱정된다: `hongbo draft` 의 사용량 줄을 보세요. 글 한 편 약 $0.15(Claude Sonnet 기준), 사진 판정(--rank)은 장당 약 $0.005 입니다. 오픈클로 자체 대화 비용은 별도입니다.
