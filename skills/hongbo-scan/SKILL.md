# 제주 초등학교 학교소식 훑기 (모든 학교)

선생님이 "학교소식 훑어 줘", "오늘 뭐 올라왔어", "다른 학교는 뭐 하나", "훑기"라고 하거나 예약 실행(아침)이 이 스킬을 부를 때 씁니다.

## 하는 일
1. 셸에서 `hongbo scan --json` 을 실행한다.
   - 새 글이 있는 페이지만 넘기며 제주 모든 초등학교의 새 글을 보관함에 저장한다(본문 포함). 유치원 글은 세지만 요약에서는 뺀다.
   - `--max-pages` 는 10을 넘기지 않는다. 하루에 세 번 넘게 돌리지 않는다.
2. 결과의 `digest` 는 이미 사람이 읽을 요약문이다. **그대로 보내면 된다.** 줄이거나 다듬어도 되지만 새 사실을 덧붙이지 않는다.
3. `activities` 중 `state: "new"` 가 있으면 마지막 줄에 "「폴더 이름」 초안 만들어 줘" 라고 말하면 시작된다고 덧붙인다.
4. `errors` 가 있으면 감추지 말고 "확인 못 한 것" 으로 함께 알린다.

## 보관함으로 더 묻는 경우
- "한림초는 최근에 뭐 올렸어?" → `hongbo archive list --school 한림초 --limit 5 --json` → 날짜·제목을 나열한다.
- "그 글 전체 보여 줘" → `hongbo archive show <글번호> --json` → 제목, 본문, 사진 수, 주소를 보낸다.
- "이번 달 어떤 주제가 많았어?" / "어느 학교가 많이 올려?" → `hongbo archive stats --since 2026-09-01 --json`.
- "진로 관련 글 모아 줘" → `hongbo archive list --topic 진로 --limit 10 --json`.
- "다른 학교 글을 예시로 쓰고 싶어" → 초안을 만들 때 보관함의 최근 글이 자동으로 참고 예시로 붙는다고 알려 준다(설정 `draft.recentExamples`, 기본 12편).

## 규칙
- 다른 학교 글은 **주제와 문체를 참고**하는 용도다. 그 내용(활동, 인원, 이름, 인용문)을 우리 학교 글에 옮겨 쓰지 않는다.
- 첨부파일은 내려받지 않는다. 글 본문과 첨부 파일 이름까지만 본다.
- 요약문에 없는 수치나 평가("가장 인기 있는 주제는…")를 지어내지 않는다. `topics`, `bySchool` 의 숫자만 쓴다.
