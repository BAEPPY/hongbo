# 홍보글 초안 만들기 → 확인 → 승인

"「폴더」 초안 만들어 줘", "안전체험관 글 써 줘", "3학년 진로체험 올릴 준비해 줘" 같은 요청에 쓴다.

## 절차
1. 폴더 이름이 불확실하면 `hongbo list --json` 으로 `activities` 를 보고 고른다. 둘 이상 비슷하면 선생님에게 어느 것인지 묻는다.
2. `hongbo draft "<폴더>" --json` 을 실행한다.
   - 사진 판정까지 원하면(`--rank`) 사진 한 장마다 AI 호출이 늘어 비용이 조금 든다. 선생님이 "사진도 골라 줘"라고 했을 때만 붙인다.
   - 오류 `메모에 대상·활동명·내용이 없어…` 가 나오면 선생님에게 그 항목만 물어서 폴더에 `메모.txt` 를 만들어 주고 다시 실행한다. **내용을 대신 지어내지 않는다.**
3. 결과를 이렇게 보낸다:
   - 제목 한 줄, 빈 줄, 본문 전체 (문단 사이 빈 줄 유지). 글을 요약하거나 줄이지 않는다.
   - 사진: `photos.picked` 의 파일을 사진으로 첨부해 보내고, 각 사진의 번호·`analysis.caption` 을 적는다. `facesCloseup` 이 true 인 사진은 "얼굴이 크게 나옴 — 빼는 것을 권함" 이라고 표시한다.
   - 마지막에 사용량 한 줄(`usage`: 입력·출력 토큰, 비용).
   - "이대로 올릴까요? 고칠 곳이나 바꿀 사진 번호를 말씀해 주세요. 확인 창으로 보시려면 '확인 창 열어 줘'." 라고 묻는다.
4. 수정 요청이 오면:
   - 글 자체를 다시 쓰라는 요청("더 짧게", "소감 빼 줘", "4문단으로")은 `hongbo draft "<폴더>" --note "<요청 그대로>" --json` 으로 다시 만든다.
   - 특정 문장만 고치는 요청("두 번째 문단의 '13개 학급'을 '12개 학급'으로")은 네가 직접 고친 본문을 임시 파일에 저장하고 `hongbo edit "<폴더>" --body-file <임시파일>` (제목은 `--title "…"`) 로 반영한다. 고친 뒤 바뀐 문단만 다시 보여 준다.
   - "확인 창 열어 줘" 는 `hongbo review "<폴더>" --detach` 를 실행하고 "브라우저에 확인 창이 열렸습니다. 거기서 승인하셔도 됩니다." 라고 답한다.
5. 선생님이 "좋아", "올려도 돼", "승인" 이라고 하면 `hongbo approve "<폴더>" --photos 1,3,4 --json` (사진 번호는 선생님이 고른 것, 말이 없으면 생략해 추천 사진 그대로) 을 실행하고, "승인 기록했습니다. '올려 줘' 라고 하시면 교육청 게시판에 올리는 절차를 시작합니다." 라고 답한다.

## 절대 규칙
- 메모와 폴더 이름에 없는 사실(날짜, 인원, 학급 수, 강사 이름, 수상, 인용문)을 **절대 보태지 않는다.** 모르면 묻는다.
- 초안 본문을 임의로 바꿔서 보내지 않는다. 바꿨다면 `hongbo edit` 으로 반영해 파일과 채팅이 같게 한다.
- 승인 없이 `hongbo approve` 를 실행하지 않는다.
- 학생 이름은 넣지 않는다. 메모에 학생 이름이 있으면 글에는 "학생들", "참가 학생" 으로 쓰고 선생님에게 알린다.
